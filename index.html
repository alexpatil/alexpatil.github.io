01

MT5 Trade Copier System

MT5 Node.js MQL5 REST API

Problem

Retail traders managing multiple MT5 accounts needed trades executed simultaneously across all accounts — with zero latency and no manual intervention.

Solution

Built a real-time trade copier: a Node.js server acts as the bridge between a master MT5 account and multiple slave accounts. An MQL5 EA on the master pushes trade signals via HTTP; the server fans them out instantly to all connected accounts.

Impact

Trades copied in under 80ms average. Supports 10+ slave accounts per master. Zero missed trades in 6 months of live operation. Eliminated the need for paid third-party copy services.

02

Government Form Automation Bot

Puppeteer Node.js SQLite

Problem

Tehsil-level government operators were manually filling identical forms on citizen portals — each submission taking 8–12 minutes. Hundreds of submissions daily created backlogs and errors.

Solution

A Puppeteer-based automation bot that reads citizen data from a local SQLite database and submits forms programmatically. Includes CAPTCHA detection logic, retry handling, and a simple dashboard showing submission status.

Impact

Submission time dropped from ~10 min to under 45 seconds. Operators now queue batches overnight. Error rate reduced by 90%. Used daily in active tehsil offices.

03

Chrome Extension for VLE Workflows

Chrome Extension Manifest V3 JavaScript

Problem

Village Level Entrepreneurs (VLEs) interacting with government portals faced repetitive multi-step flows for every citizen request — login, navigate, fill, verify, submit, download. All manual.

Solution

A Chrome Extension using content scripts to inject automation logic into existing portal pages. The extension detects page state, fills fields from cached citizen profiles, and automates navigation steps — all without modifying the portal itself.

Impact

Each citizen request now takes 2–3 minutes instead of 15+. Extension distributed to 40+ VLE operators. Zero portal compatibility issues — works with the live production portal.

04

EUR/USD Algorithmic Trading Bot

Python MQL5 MT5 Pandas

Problem

Discretionary trading on EUR/USD introduces emotion, inconsistency, and missed setups during off-hours. A systematic edge needed to be codified and automated.

Solution

A Python-based strategy engine that analyses price action, session timing, and momentum indicators to generate trade signals. Signals feed into an MQL5 EA that executes on MT5 with ATR-based SL/TP and position sizing logic.

Impact

Backtested over 3 years of tick data. Consistent positive expectancy across London and NY sessions. Runs 24/5 on a VPS — no manual intervention required.
